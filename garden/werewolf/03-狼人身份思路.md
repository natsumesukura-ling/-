# 一、最底层的视角：把自己当成“闭眼民”

- 拿到狼人身份后，夜里当然知道狼队友是谁；但进入白天发言、判断和投票时，要尽量隔离这层阵营信息。

- 核心自我提醒：我没有队友；我没有好人阵营的夜间信息；我不知道场上谁好谁坏。

- 从一个普通闭眼玩家的公开视角重新判断：听完这些发言、看到这些票型和公开信息以后，我自然会怀疑谁、认可谁、投谁。

- 不要围绕“他是我队友”设计动作。保队友、救队友、刻意卖队友、为了做身份突然踩队友，本质上都可能让自己的行为被狼队关系污染。

- 目标不是表演一种固定的“好人样子”，而是让自己的推理来源和行动路径符合一个不知道阵营答案的玩家。

# 二、发言与投票：不要为了队友扭曲自己的公开逻辑

- 发言时，不因为某个人是队友就下意识替他解释、找补或保一手。

- 投票时尤其不要因为“队友快被票出去了”就临时改变原本自然的投票逻辑去救他。

- 如果按照自己的闭眼民视角，本来就应该投那个狼队友，就正常投。必要时接受队友出局，优先保住自己的自然身份状态。

- “死道友不死贫道”不是要求主动卖队友，而是不要为了挽救一个已经危险的队友，把第二匹、第三匹狼一起暴露。

- 反过来也不要为了做高自己身份而无理由往死里揪队友。如果闭眼民视角没有足够理由重踩，就不要突然重踩。

- 投票和发言都应首先回答：如果我真的不知道他的身份，我现在会怎么判断？

# 三、最好的保有时是无视：不要主动续狼队关系

- 如果悍跳狼队友已经被票出局，尤其不要主动在后续发言里讨论这个队友是好还是坏，也不要特意拉、踩或撇清。

- 已经出局的狼队友留下的关系线，如果场上没有人捡起来，就让它自然消失。不要自己主动把它重新搬回桌面。

- 悍跳狼队友如果曾给自己发好人卡、金水，或在遗言里保过自己：没有其他玩家质疑时，就当这件事暂时不存在，不主动解释。

- 主动说“虽然他保了我，但我跟他没关系”之类的话，会亲手提醒全场去盘自己与悍跳狼之间的关系，反而可能把原本藏好的深水狼暴露出来。

- 只有当其他玩家已经明确拿这段关系攻击自己时，才需要回应。回应时重点解释自己的公开行为和逻辑为什么独立成立，而不是急着证明自己和出局者没有关系。

- 原则：狼队友留下的关系线，没人捡就让它烂在地上；别人捡起来打我，我再处理。

# 四、被票出局时：先判断自己是不是已经成为“铁狼”

遗言思路要根据自己在全场眼中的身份状态区分。不要把两种情况混在一起。

## 情况 A：全场已经基本默认我们是狼

- 此时遗言的主要价值不再是认真维持闭眼民身份，而是搅浑后续关系判断、制造噪音。

- 可以对好人进行明显的拉、踩、抬，故意制造真假难辨的关系，让好人第二天需要额外判断哪些关系是狼临死前故意留下的。

- 尽量不要提真正的狼队友。无论保真队友还是踩真队友，都可能给好人留下分析入口。

- 既然目标是制造假关系，就优先拿好人制造关系，不必把真实狼队关系送进信息池。

## 情况 B：我们只是被票出去，但并没有被全场坐实为狼

- 继续按自己整局建立的闭眼民视角发表遗言，不突然切换成明显的“狼遗言”。

- 该盘谁、怀疑谁、认可谁，应与生前的公开逻辑保持连续。

- 仍然尽量不主动提真队友。

- 如果公开局势已经把队友摆到面前，完全绕开反而显得不自然，可以正常提及；必要时可以小踩一脚，但不要为了做关系突然用力过猛。

- 目标仍然是维持一个不知道真实阵营的玩家应有的自然视角。

# 五、狼队关系的统一思路

- 不要主动经营狼队关系。

- 不主动保、不主动救、不主动撇、不主动踩，也不因为知道队友身份而刻意避开所有正常互动。

- 公开局势没有把队友关系推到自己面前时，不主动处理；公开局势真的要求自己回应时，再以闭眼民视角自然处理。

- 活着时尽量不给好人制造可追踪的真实狼队关系；出局时也尽量不给好人留下真实队友关系。

- 狼踩狼、狼保狼都不是禁招，也不是固定策略。是否发生应由当局公开逻辑自然产生，而不是为了“做身份”机械执行。

# 六、狼夜：利用协作窗口，但不要把白天视角带坏

- 狼人夜间频道是狼队真正可以明确协作的窗口。应在狼人回合结束前完成必要的刀口讨论、风险判断和次日大方向沟通。

- 狼人频道在狼人回合内可以多次发言，但狼人回合结束后不能继续补充，因此重要事项不要拖到最后。

- 刀口不只考虑“谁像神”。还可以结合谁在组织好人、谁次日可能形成带队能力、当前人数结构和胜负条件判断。

- 接近胜负节点时，重新计算存活身份结构非常重要。有时直接满足屠边/当局胜利条件的刀口，比追求击杀某个神职更关键。

- 夜里可以明确知道队友和共同计划；到了白天，则重新切回闭眼民视角，避免把夜间已知答案泄漏进发言。

# 七、悍跳与队友配合：关系可以存在，但不要机械维护

- 悍跳狼可以通过假验人等方式建立场上关系，但这些关系以后也可能成为好人回盘狼坑的线索。

- 其他狼不应因为队友在悍跳就机械站边、机械冲票或机械维护。仍然要考虑自己作为一个闭眼玩家是否有足够公开理由做出相同行为。

- 悍跳狼出局后，存活狼尤其不要主动替其遗言、验人或好人卡续关系。

- 如果悍跳狼给自己留下了明显关系，而场上暂时没人追究，优先保持沉默和自然游戏；只有关系真正成为公开质疑点时再处理。

# 八、自爆：把它当成局面工具，而不是固定动作

- 花园规则下，狼人自爆会直接跳过一整个白天的发言与放逐，因此自爆具有切断当日信息产生和投票流程的效果。

- 是否自爆必须结合当局收益判断：后置位是否还有重要发言、继续白天是否更有利于好人、跳过放逐后夜间结构如何变化等。

- 自爆不是“身份暴露就一定爆”，也不是“永远不爆”。这里只记录其战略意义，实际使用看具体局面。

# 九、这份参考最重要的边界

- 本文全部是行动思路参考，不是必须照做的规则。

- 任何具体局面都可能要求例外处理；如果机械执行某条建议反而让行为不自然，应优先服从当局逻辑。

- 不使用固定发言模板，不预制“狼应该怎么说”。发言内容必须根据当轮真实信息现场组织。

- 如果本文与花园实际系统机制或明确规则冲突，以花园当局系统与规则为准。

- 最终目标不是“按攻略扮狼”，而是在拥有狼人真实信息的同时，白天能够从合理的闭眼视角独立思考和行动。

**一句话提醒：夜里我们有队友；白天先忘掉队友。关系不主动做，局势推到面前再自然处理。**
